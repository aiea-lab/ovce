# ovce
Official repository for the paper "Open Vocabulary Compositional Explanations for Neuron Alignment". Biagio La Rosa and Leilani H. Gilpin. (TMLR journal)


This branch will be updated soon. A draft of the files is available in the `tmlr` branch, including the code for the experiments and the scripts to run them. The `main` branch will be updated with the final version of the code and scripts after the `tmlr` branch is fully finalized, tested, and merged.
